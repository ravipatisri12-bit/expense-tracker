# ⚡ Quick Start Guide - Smart Expense Input

## 🎯 Goal
Add expenses 3x faster using natural language and AI.

## 📋 Setup (2 minutes)

### Step 1: Get Free API Key
```
1. Go to: https://makersuite.google.com/app/apikey
2. Sign in with Google
3. Click "Create API Key"
4. Copy the key (AIza...)
```

### Step 2: Configure App
```
1. Open expense tracker
2. Click "Add" tab
3. Click "Configure AI"
4. Paste API key
5. Click "Save"
```

Done! 🎉

## 🆘 Quick Troubleshooting

### Problem: Parse button doesn't work
```
Solution: Check API key in "Configure AI"
```

### Problem: Wrong category
```
Solution: Manually change before submitting
Tip: Use category keywords next time
```

### Problem: Amount not detected
```
Solution: Include $ or "dollars" in input
Example: "$45" or "45 dollars"
```
